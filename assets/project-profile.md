# 项目接入信息模板

仅在需要长期重复使用且项目尚无等价入口时填写；将填写后的内容保存在项目约定的位置。本模板保留在 Skill 中，不保存某个项目的当前状态。

## 用户目标与验收

- 当前产品服务谁，完成什么任务：
- 最短成功路径及可观察结果：
- 已知约束、预算与关键未知：

## 权威入口

- 项目说明与 AGENTS.md：
- 架构/数据归属/契约真相源：
- 本地启动与依赖约定：
- 现有任务主记录或 Issue：

## 实现与验证

- 主要模块与职责：
- 必要验证命令、运行目录、环境前提：
- 集成测试与业务冒烟入口：
- 已知基准失败及证据：

## 发布操作

- 源仓库与目标分支的项目内引用：
- 现有 CI/构建/发布入口：
- 目标环境与访问方式的安全引用：
- 凭据的安全存储位置引用（不填写密钥值）：
- 迁移顺序、健康/业务检查与回退说明：

## 决策记录

- 已接受的取舍与适用条件：
- 项目特有确认边界：
- 内容最后核对日期与版本：

未确认项明确写“未知”。主机地址、身份与未公开配置依项目规则保存在私有文档，不写回通用 Skill。
