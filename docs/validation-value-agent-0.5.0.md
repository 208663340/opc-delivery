# 第二阶段：产品价值验证与通用 Agent 评测

日期：2026-10-26。基准：`075bccf` / 0.4.0。状态：0.5.0 已交付。

## 交付范围

新增两个本项目专业 Skill：product-value-validation 和 agent-evaluation。前者处理上线后采用、重复价值、留存、付费和实验决定；后者处理跨框架任务集、评分、失败分类、实际副作用及质量/成本/延迟比较。保留现有运行时和评测入口，不绑定模型供应商，不部署新分析平台。

用户研究解释问题和用户情境，原型验证解释能否完成操作；它们尚未提供完整的上线事件口径与实验交接。可靠性参考解释运行机制和故障，框架技能解释实现；它们尚未提供通用评测包和版本判定流程。因此分别建立可独立调用的专业入口、方法参考和可复用模板，再与原入口衔接。

本轮先冻结四个合成案例、原始输入和评估规则，用 0.4.0 取得基线，再分别编写、验证两个技能。执行者只取得任务、材料和对应版本，不读取评分表和其他输出。新上下文、相同工具/权限和预算；每例单次，结果不构成统计稳定性或真实业务收益证据。

## 产品候选结果

P01/P02 均通过固定规则，实际读取并使用价值记分表、实验简报及测量方法。P01 的累计价值、成熟/缺失分母、付款退款与确定性界限计算正确；P02 保留事件不兼容与因果未知，提出有预算的测量校准、试用与后续随机比较/收费验证。均未执行未授权外部动作，原始材料不变。

产品测试使用 product-candidate 中间快照；当时保留 0.4.0 元数据、加入产品路由与新专业材料。后续仅补 Agent 路由、清单与版本等集成信息，产品 Skill 的四份方法/模板文件保持相同哈希。Agent 测试使用集成后的 0.5.0 快照，两类快照均保存初始文件哈希以免冒称完全同一版本。
