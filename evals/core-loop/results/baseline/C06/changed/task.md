## 离线 CSV 校验清单（已整理，产品验证待执行）

以下依据 csv-format.md；示例为合成数据。示例中的规范表头仅用于说明字段，不代表已实现自动列识别。

| 场景 | 合成输入示例（数据行） | 既有规则对应的预期 |
| --- | --- | --- |
| 正常值与零金额 | `苹果,0`；`香蕉,125` | 字符串 item 非空，金额为非负整数，字段校验通过 |
| item 缺失 | `,125`；`"",125` | item 必填校验不通过 |
| 金额缺失 | `苹果,` | amount_cents 不是非负整数，校验不通过 |
| 负金额 | `苹果,-1` | 校验不通过 |
| 非整数或非数字金额 | `苹果,1.5`；`苹果,abc` | 校验不通过；不得以截断或默认零掩盖无效值 |
| 完全相同重复行 | 连续或隔行出现两次 `苹果,125` | 按既定规则拒绝导入；检查整个文件而非仅相邻行 |
| 相同 item、不同金额 | `苹果,125` 与 `苹果,126` | 不属于完全相同重复行，不应仅因 item 相同触发该规则 |
| 不同 item、相同金额 | `苹果,125` 与 `香蕉,125` | 不属于完全相同重复行 |
| 引号内逗号 | `"苹果,大号",125` | 解析为两个字段，item 保留内部逗号；随后执行字段校验 |
| UTF-8 中文 | UTF-8 编码的 `苹果,125` | 正确解码，不损坏字段内容 |
| 非 UTF-8 或非法编码序列 | 非 UTF-8 字节样本 | 判为不符合文件编码约定；不能把乱码作为成功导入 |

需补充规则后再确定预期的边界：仅空白的 item 是否为空、是否去除首尾空白；空行和空文件；金额前导零、加号及取值上限；缺失或多余列、非闭合引号的报错行为；重复判定是否在格式规范化之后进行。这些是未定义项，不作为本轮新增验收条件。自动识别的列名、列序、歧义和失败处理验收样例，待替代方案及对应规则确认后补齐。
