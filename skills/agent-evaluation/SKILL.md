# 通用 Agent 评测

用可复现任务判断 Agent 是否在约定权限、状态和预算内完成了正确结果。适用于自研循环及不同框架；先复用项目已有 eval 入口、fixture、状态 owner 和真实验收，不要求迁移运行时或接入特定供应商。

## 确定当前决定

先读项目评测入口和现有失败记录，明确：评什么能力或回归、比较哪些版本、允许的运行范围、需要什么证据才决定修复或替换。已有 trial 时直接重算与诊断，不先搭建新框架。

| 当前工作 | 按需读取 | 应交回的证据 |
| --- | --- | --- |
| 定义任务、比较与运行方案 | [评测计划](assets/eval-plan.md) | 任务来源、划分、固定条件、预算和决策依据 |
| 准备数据与判分 | [运行与判分方法](references/trial-and-grading.md) | 独立案例、评分规则、状态/副作用断言与校准 |
| 需要字段示例 | [案例](assets/case.example.json)、[独立答案](assets/oracle.example.json)、[trial 记录](assets/trial.example.json) | 适配既有 schema 的输入、oracle 和实际运行记录 |
| 已证实运行机制故障 | [可靠性审查](../../references/reliability-review.md) | 既有 owner 内的根因与最小回归 |

示例只是数据结构，不是可直接运行的评测框架；保留项目 schema，将字段映射进去。不要改现有 runner 只为迎合示例，也不复制业务状态机。模板中的空值和 `not_run` 必须等真实证据后再更新。

## 建立能区分版本的任务

1. 从实际目标、已有失败与代表性工作中选任务，覆盖正常完成、缺信息、必要确认/取消、工具失败、结果未知恢复和资源耗尽。合成案例标明身份，不能当生产分布或真实用户收益。
2. 每例固定 Agent 可见输入、初态与可用工具；独立保存 oracle、结果约束、隐藏故障安排和证据要求。评估答案不放进 Agent 提示、检索库或可读目录；用户提供的授权和业务规则则应正常可见。
3. 分开任务开发/回归集与未参与模型、提示或工具调优的任务保留集。相似模板、同一用户/文档变体按组划分以防泄漏。保留集被用于改进后不再称未见；换新集或降低声明。评分器校准的留出集是另一件事，不能替代任务保留集。
4. 为正确完成、合理等待/澄清/拒绝与失败写可观察的标准。完成必须看实际产物或权威状态；“我已创建”不等于真实写入。允许多条合法工具路径，不用固定措辞或步骤数替代结果标准。

## 运行与评分

冻结任务/fixture/oracle、模型与提示、代码、工具 schema、环境、采样配置和累计预算。比较时尽量只改变目标因素，说明无法对齐之处。每次 trial 重置状态、缓存和工具替身；恢复案例的预置状态是任务的一部分，不能被重置掉。

先做已有入口的格式或 dry-run 检查，再运行获准的 Agent 与评分。分别记录“数据有效”“Agent 已运行”“评分已完成”，前者不证明后两者。没有执行后端时交付可校验的材料和具体适配缺口，不虚报结果，不擅自调用付费 API。

- 确定性规则优先检查计算、终态、产物和真实副作用；轨迹用于定位原因。既有确认、取消、权限和重复写入约束不能被平均质量分抵消。
- 语义质量用有明确锚点的评分表；模型 judge 先与有依据的参考标签校准，记录分歧和错误类型。没有真人/专家复核时如实标未校准，不能自称获得人工金标。
- 多次 trial 保留失败、超时和未知。公布计划/实际/可判分/通过数量；运行器故障与 Agent 失败分开，但不把坏结果删掉再报满分。
- 区分单次成功、重复中至少一次成功、重复中每次成功。小批观察比例不是总体稳定概率；不能用“多试几次总会成功”证明可无监督发布。
- 成本和延迟覆盖失败、重试与工具开销，缺账或缺测保留未知。尾延迟附样本量；便宜和快速不能抵消越权或不正确结果。

## 交回判断与改进

按任务和风险类别列出配对结果、实际证据、最先失败的环节及未验证部分。门槛来自产品验收、风险容忍和可用预算；没有门槛时先建立基线，不编造通用成功率。

错误评分先修评分；任务不明确先修任务；真实 Agent 问题回到现有 owner 做最小修复，并将失败加入开发回归集。冻结候选后再用未见任务验证，不把同一批调参结果当独立泛化证据。

结论可以是保留现版、修复后复测、进入获准的小范围试用或证据不足。离线通过不等于生产发布已获准，也不证明真实用户持续价值；需要产品价值判断时转入 [product-value-validation](../product-value-validation/SKILL.md)。
