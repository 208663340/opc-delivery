## 范围与对照条件

本轮围绕已确认的设计，明确目标条件、下一动作选择、阶段证据、专业技能交接与结束条件。保留 30 项专业技能及 CLI/Python 工具行为。

在编辑运行 Skill 前冻结 C01–C08，先运行旧版。每个案例、每个版本是一个新的无对话历史 Agent；提供相同原始材料、工具权限与最多 20 次工具调用的预算，模型配置均继承同一主会话。每例单次执行，不代表稳定成功率。没有可靠的 token、计费或时长遥测，均未测量；命令清单由执行者自报，不冒称完整工具审计。

执行者只收到任务、独立夹具和该组技能快照，不能读取评分表或另一组输出。隔离依赖明确指令及独立目录，未实现操作系统访问隔离。评估者另行核对产物、文件差异、操作日志和声明范围。C05 使用无网络的本地部署替身；其他数据同样是合成材料。

本轮止于离线可完成工作或首个待答决策点，没有真人追问答复、招募、付费、真实平台发布或生产恢复。用户答复规则已冻结，未执行多轮对话；不能据此宣称整个产品交付闭环已测量。

开发评测材料和原始记录存放在仓库的 [evals/core-loop](https://github.com/208663340/opc-delivery/tree/main/evals/core-loop)。评测输入、输出不作为运行技能依赖，也不进入 npm 技能安装载荷。
