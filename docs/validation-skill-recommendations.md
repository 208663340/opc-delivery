- 新增 [专业 Skill 推荐](../references/skill-recommendations.md)：七个领域、18 项可选候选，包含来源、适用条件与应交回的证据。

- 按实际问题加载候选，保留项目的既有框架、验收和主记录；候选不可用时用已有能力继续推进。

## 格式、来源与脚本

- 官方 `quick_validate.py`：通过。
- Markdown 内部相对链接：全部可解析。
- 18 项外部候选：通过 GitHub 连接读取真实 `SKILL.md`，核对链接、frontmatter 名称及其声明的适用范围。未把源目录名当作技能名称；ECC 使用更名后的 `affaan-m/ECC` 地址。
- `python3 scripts/test_delivery_tools.py`：原有 22 项测试通过；本次没有修改脚本。

来源核对不等于外部技能的完整行为审计、依赖兼容性测试或安装状态检查；具体选用时仍需读取当前环境中的实际说明。

## 隔离检索与应用测试

执行者未继承制作过程或预期答案，只获得请求、目标技能路径与所需原始材料。测试只读、离线，不执行候选安装或业务代码修改。

| 输入 | 实际结果 | 能证明的范围 |
| --- | --- | --- |
| 旧版对照：询问七类真实交付问题对应的专业 Skill，安装清单未知 | 如实指出缺少推荐清单；只能定位内部阶段参考，不能提供材料支持的专业 Skill 名称 | 旧版存在推荐检索缺口；没有把内部参考误称为独立 Skill |

## 后续增量：收录本地技能快照

同日根据用户要求，将推荐清单的 18 项主要 Skill 和 9 项 Agent / Python 配套 Skill 的本地目录一并收录，共 27 项、140 个原有文件，约 608 KB。来源包括本机的个人技能目录与共享技能目录；公开清单保留上游地址，不记录个人绝对路径。

主要推荐表的技能名称改为包内链接；生态入口所引用的 RAG、middleware、依赖、持久化、人工介入、记忆和编排专题，以及 Python ORM 与测试专题均可沿本地路径读取。保留完整规则、参考和原有许可文件。

来源与每个文件的源快照、打包 SHA-256 记录在 [manifest.json](../skills/manifest.json)。Vercel React 的生成 `AGENTS.md` 原有三处链接指向同目录，但目标实际位于 `rules/`；打包时仅修正这三处相对路径，记录在 `local_changes`，保留源文件校验值。其他文件保持原字节内容。
