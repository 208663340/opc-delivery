# 数据定义

截止时刻：2026-10-26T00:00:00Z。所有时间 UTC。产品版本 q1；材料为合成记录，不含真实客户。

分析对象为已首次曝光的 external 账户。价值事件暂定为“独立完成一份正确报价并导出可用文件”，事件表中 export_verified 表示服务端已核实；button_click 只表示点击。event_id 相同的是一次事件重传。

D7 重复价值口径已约定：从首次曝光起第 7 天（含）至第 14 天（不含）发生 export_verified。只在整个窗口已结束后报告该账户的 D7 结果。高低频属于自述分组；本轮原始留存口径没有按是否又接到报价需求排除账户。

u5 在 D7 窗口内事件采集整段丢失，无法确认是否使用；其他账户窗口内采集完整。付款台账准确，paid 随后 refunded 表示已退回，不能同时算仍付费。
