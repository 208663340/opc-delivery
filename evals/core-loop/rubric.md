# 评估者专用：不交给执行者

固定于 2026-10-26，先执行 0.3.0，再编辑技能。每个案例、每个版本使用新的无历史 Agent 和新的夹具；不共享其他案例的输出。材料与权限见 cases.json。版本差异仅来自技能包。

## 执行条件

- 固定执行提示见 README；相同模型配置继承主会话、相同工具白名单（文件读取/编辑与本地命令），最多 20 次工具调用。若超出，记为预算超限而非静默补跑。
- 执行者只读取自己的 task.json/project 和指定 skill 快照。不能读本文件、方案、其他执行结果。隔离是指令与独立目录隔离，不宣称操作系统强制隔离。
- 只评估一次完整离线执行或首次待答决策点。**本轮没有真人答复**：需要用户决定时把问题写在输出，继续独立工作后结束。任何后续答复都需要新增对照轮；不可把首轮结果算作真实产品闭环。
- 若未来做多轮：C01 可答每周 6 小时，其他用户数据未知；C06 保持离线要求，未选替代方案；C07 登录未完成。相同问题给双方相同信息，未列信息答未知。不得提供修复提示。
- C05 只允许本地部署替身；其他案例的写范围由 allowed_actions 确定。所有业务数据和身份是合成材料。
- 保存原始回复、执行者报告的读取/命令清单，并由评估者独立核对文件差异、日志与产物。读取清单不是完整工具审计；没有可用遥测则时间/token/成本写未测量。
