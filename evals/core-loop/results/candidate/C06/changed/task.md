## 离线 CSV 校验清单（已完善，待实现后执行）

以下是基于 `csv-format.md` 的验证样例与预期，不是已运行的测试结果。记录样例按标准字段顺序 `item,amount_cents` 展示；不代表已完成列识别或定义了任意表头的映射规则。

| 场景 | 输入或构造 | 校验预期 |
| --- | --- | --- |
| 正常记录 | `纸张,1250` | item 为非空字符串，金额为非负整数，应通过字段校验 |
| 零金额边界 | `纸张,0` | 0 合法，不得当作空值 |
| item 空值 | `,100` 或 `"",100` | 必填字符串缺失，校验失败 |
| 金额空值 | `纸张,` 或 `纸张,""` | 不能作为合法非负整数导入，不得静默按 0 处理 |
| 负金额 | `纸张,-1` | 非负约束失败 |
| 非整数金额 | `纸张,1.5` | 整数约束失败，不得四舍五入 |
| 非数字金额 | `纸张,abc` | 整数约束失败，不得静默转换 |
| 完全相同的重复行 | 同一文件内两条 `纸张,100`，分别覆盖相邻和间隔出现 | 按现有约定拒绝导入，不得静默去重 |
| 非完全相同记录 | `纸张,100` 与 `纸张,101`；`纸张,100` 与 `信封,100` | 不得仅因 item 相同或金额相同就认定为完全相同的重复行 |
| 引号内逗号 | `"纸张,加厚",100` | 解析为两个字段，item 保留内部逗号；不得用简单字符串 split 拆列 |
| UTF-8 中文 | UTF-8 编码的 `纸张,100` | 中文正确保留，不出现乱码 |
| 非 UTF-8 文件 | 用其他编码构造的含中文文件 | 不满足 UTF-8 约定；不得悄悄替换乱码后继续导入 |

执行时需保留：脱敏或合成输入、实际错误/结果、所测版本、运行命令；涉及拒绝导入的案例须确认未留下部分导入数据。使用合成 CSV，无需上传真实报价。

当前格式尚未定义的边界须显式留待核对，不能在清单中暗定新规则：纯空白 item 是否视为空；金额的前后空白、前导零、加号、科学计数法及数值上限；引号写法或金额文本不同但解析值相同的记录是否算完全相同重复行；表头识别/缺失/歧义的处理。上述边界目前没有通过证据，也不作为本次擅自新增的验收要求。
