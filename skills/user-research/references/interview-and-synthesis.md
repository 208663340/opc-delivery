# 访谈、样本与证据分析

## 把问题限定到最近的实际事件

按“背景 → 最近一次任务 → 关键变化 → 替代办法 → 不采用条件”组织访谈。先让参与者叙述，追问具体操作、参与者、产物与时间依据；自愿展示的文件应脱敏。区分操作耗时、等待时间与回忆估算。

| 容易诱导的问法 | 可调查的问法 |
| --- | --- |
| 这个功能能省很多时间吧？ | 最近一次在哪里花了时间？你如何判断？ |
| 如果我们做出来，你会付费吗？ | 最近一次为解决类似问题投入钱或迁移时间是什么情况？谁决定？ |
| 你是不是也很讨厌现在的工具？ | 哪些情况原工具已经够用？什么时候你会继续使用它？ |

过去付费也不证明会为本产品付费。方案评价单独记录，避免混入对现状的观察。

## 招募与轮次

筛选围绕真实任务经历、频率、角色和限制，不只按年龄、职业名或“喜欢新技术”。保留至少需要比较的差异，例如高频与低频、使用者与付款决策者、已迁移与坚持原办法的人；这些是研究设计候选，不要求每次覆盖所有分组。

先写想解决的未知和本轮覆盖范围。下一轮针对仍会改变决策的缺口调整样本；“几个人说过”不能直接推出市场占比。问卷比例需要明确抽样、样本数、题目和缺失情况，不能用访谈样本包装为总体统计。

## 从材料到发现

1. 给原始材料和参与者编号，保留可核对的时间或位置引用；别把 AI 补写内容混入原始转录。
2. 提取每条可观察事件和自述，写明其来源类型。推断另列，并寻找相反解释。
3. 对比任务、代价和替代方案形成主题。保留不符合主题的样本，不为“结论统一”删掉反例。
4. 每项发现填写：证据 ID、观察、解释、反证、适用边界、会改变的产品决定。
5. 对暂缓决定说明下一条证据及取得方式；与现有需求或 PRD 交接，不另建一套产品状态。

只收到两条访谈时，先完成这两条的分析与下一轮设计，不虚构更多参与者、饱和程度、付费承诺或已经执行的访谈。
